VNPay Sandbox Setup Instructions:
==================================

1. Register VNPay Merchant Account
   - Go to https://sandbox.vnpayment.vn
   - Register for a merchant account
   - Wait for account approval (usually 1-2 business days)

2. Get Sandbox Credentials
   After approval, log in to your VNPay Merchant account and navigate to:
   - Settings → API Information
   - Copy the following credentials:
     * TMN Code (Merchant ID): Example format like "2T2K9JQK"
     * Hash Secret: Long alphanumeric string for HMAC-SHA512 calculation
     * API URL: https://sandbox.vnpayment.vn/paygate/pay

3. Update VNPayService.java
   - Open: src/java/services/VNPayService.java
   - Find lines 18-19:
     
     private static final String VNP_TMN_CODE = "TMN_CODE"; // Replace with your TMN Code
     private static final String VNP_HASH_SECRET = "HASH_SECRET"; // Replace with your Hash Secret
   
   - Replace "TMN_CODE" with your actual merchant code (example: "2T2K9JQK")
   - Replace "HASH_SECRET" with your actual hash secret

4. Testing in Sandbox
   After configuration, test the payment flow:
   
   a) Login to the application
   b) Navigate to Wallet (http://localhost:8080/PRJ301-EVehvicleRental?page=wallet)
   c) Click "Nạp tiền" (Top-up) button
   d) Enter an amount (e.g., 100,000 VND)
   e) Click "Nạp tiền qua VNPay"
   f) You'll be redirected to VNPay sandbox page
   g) Use test card details:
      - Card Number: 4111111111111111 (MasterCard test card)
      - Expiry: Any future date (e.g., 12/25)
      - OTP: Any 6 digits
   h) Complete payment
   i) Verify the transaction appears in wallet history

5. VNPay Test Cards
   Below are common test cards for VNPay Sandbox:
   
   - VISA:      4012001037461114
   - MasterCard: 5123456789012346
   - JCB:        3528000000000000
   
   Note: Use any future expiry date and any OTP code

6. Callback Setup
   The application is configured to handle VNPay callbacks at:
   - Return URL: http://localhost:8080/PRJ301-EVehvicleRental/vnpay-callback
   - Ensure this URL is accessible for testing
   - For production, use your public domain URL

7. Production Migration
   When ready for production:
   a) Register production merchant account
   b) Update VNPayService.java with:
      - Production TMN Code
      - Production Hash Secret
      - Production URL: https://pay.vnpayment.vn/paygate/pay (no "/sandbox")
   c) Update return URL to your production domain
   d) Thoroughly test before going live

8. Troubleshooting
   
   Issue: "Secure hash verification failed"
   - Check that TMN_CODE and HASH_SECRET are exactly copied
   - Verify no trailing spaces in credentials
   - Check query string parameter order (must be alphabetically ordered)
   
   Issue: "Invalid transaction amount"
   - Amount must be between 10,000 and 100,000,000 VND
   - Check that amount is passed correctly
   
   Issue: "Callback not received"
   - Verify return URL matches VNPay configuration
   - Check firewall/router port forwarding for localhost testing
   - For remote testing, use ngrok or similar tunneling service
   
   Issue: "User not found in session"
   - Ensure session is active before initiating payment
   - Don't close browser tab before callback

9. VNPay API Documentation
   - Official docs: https://sandbox.vnpayment.vn/apis/docs/
   - Integration guide: Available in VNPay Merchant Dashboard
   - Support: contact@vnpayment.vn

10. Security Notes
    - HASH_SECRET must be kept confidential - never commit to public repositories
    - Always verify secure hash on both request and response
    - Use HTTPS for all payment URLs in production
    - Validate all user inputs before sending to VNPay
    - Store sensitive payment info securely
